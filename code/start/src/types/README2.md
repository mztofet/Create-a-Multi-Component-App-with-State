# Todo List Application

## Description

This project is a Todo List application built using React, TypeScript, Zustand, and Vite. It allows users to add, complete, and delete tasks while demonstrating global state management with Zustand.

## Features

- Add new todos
- Mark todos as completed
- Delete todos
- Global state management with Zustand
- TypeScript type safety
- Unit and component testing with Vitest

## Technologies Used

- React
- TypeScript
- Vite
- Zustand
- Vitest
- Testing Library
